## 🚀 Quick Start

```bash
npm start      # Start development server
npm run build  # Build for production
npm test       # Run tests
```

## 🎨 Customization

### Add Your Projects
Edit `src/data/projectsData.js` to add your projects.

### Update Skills
Modify the skills array in `src/components/Skills.jsx`.

### Change Colors
Update CSS variables in `src/styles/global.css`:
```css
--primary-color: #667eea
--secondary-color: #764ba2
```

### Add Profile Image
Place your image in `public/images/` and reference it in components.
